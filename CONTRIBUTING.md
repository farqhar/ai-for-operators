# Contributing

Ideas, fixes and new items are welcome.

**Each item lives in its own folder** with:
- `README.md`: what it's for, a 2-minute quickstart, and what good output looks like
- the files themselves (skill, template, script)
- `example/`: fictional worked data. Never real client, company or personal details.

**House rules**
- Written for people who aren't engineers. Define a term the first time you use it.
- Scripts: Python standard library only, safe by default (preview first, no deletes).
- Skills: propose before acting, and never delete user files.

Open an issue first for anything bigger than a fix, so we can agree the shape.
