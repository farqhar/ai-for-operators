# Examples (fictional)

The same project, briefed two ways. It's the weekly store report drafts, which came first in the
[prioritisation matrix example](../../prioritisation-matrix/example/).

- [`brief-vague.md`](brief-vague.md): how most briefs start. Five blocking gaps.
- [`brief-weekly-report.md`](brief-weekly-report.md): the same project, ready to build.

Run the checker on both from the `project-brief/` folder:

```bash
python3 skill/project-brief/brief-check.py example/brief-vague.md
```

```bash
python3 skill/project-brief/brief-check.py example/brief-weekly-report.md
```
